# cmscout
Clone of cmscout from https://sourceforge.net/projects/cmeditors/

## Browser version

`web/cmscout.html` is a single-file browser port that loads saves, filters and sorts entirely client-side. It supports CM4 / CM 03/04 saves and Championship Manager 01/02 saves (ported from the CM Scout 2.00 source in [CM0102/](CM0102/)). See [web/README.md](web/README.md).
