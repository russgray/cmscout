# cmscout
Clone of cmscout from https://sourceforge.net/projects/cmeditors/

## Browser version

`web/cmscout.html` is a single-file browser port of CM Scout 2.00 for Championship Manager 01/02 (Delphi source in [CM0102/](CM0102/)). It loads `.sav` saves, filters and sorts entirely client-side. See [web/README.md](web/README.md).
